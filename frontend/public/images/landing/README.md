# Landing page photography

Every file here must have an entry in [`content/image-credits.ts`](../../../content/image-credits.ts)
with its source URL, photographer, licence and the location the source records.

- Real photos only: Unsplash or Pexels for general scenes; Wikimedia Commons (CC0, CC BY or
  CC BY-SA, with attribution) for specific Cebu landmarks.
- No placeholder services, AI-generated images, identifiable third-party branding or celebrities.
- WebP (AVIF optional, same base name). Full-bleed ≤ 2400px wide, cards ≤ 1600px, ideally < 350KB.
- Name a specific place in a caption only when the source page records that location.
